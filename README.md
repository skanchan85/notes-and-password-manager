# Notes & Password Manager

A secure desktop application built with Java and Java Swing that helps users store and manage their notes and passwords safely using AES encryption.

## Overview

Managing multiple passwords and sensitive notes can be difficult and risky if stored in plain text. This application provides a simple, secure, and user-friendly way to store credentials and notes locally, with all sensitive data protected using AES encryption.

##  Features

-  **AES Encryption** – All stored passwords and notes are encrypted before saving
-  **Add/Edit/Delete Entries** – Easily manage your saved credentials and notes
-  **Search Functionality** – Quickly find saved entries
-  **Simple GUI** – Built with Java Swing for a clean, intuitive desktop experience
-  **Local Storage** – Your data stays on your device, not on any external server

## Tech Stack

- **Language:** Java
- **GUI Framework:** Java Swing
- **Security:** AES Encryption
- **Storage:** Local file-based storage

## Getting Started

### Prerequisites
- Java JDK 8 or higher installed on your system

### Installation & Running

1. Clone the repository
   ```bash
   git clone https://github.com/your-username/notes-password-manager.git
   ```
2. Navigate to the project directory
   ```bash
   cd notes-password-manager
   ```
3. Compile the project
   ```bash
   javac Main.java
   ```
4. Run the application
   ```bash
   java Main
   ```
